# 裝備材料反查 · 估價

仙境傳說 RO 守愛初心服（chuxin.romel.wiki）裝備資料的反查 / 估價工具。

## 怎麼用（一般使用）

直接雙擊打開 **`index.html`** 即可，免裝任何東西、可離線、可分享。

- **材料找裝備**：勾選一個或多個材料 → 列出用到最多你勾選材料的裝備（含帽子），依命中數排序（命中數相同時估價高的排前面），每張卡顯示該裝備的完整材料與加總成本、命中你勾選的材料以白字標示。也可只點一個材料名稱看單一材料用在哪些裝備。
- **裝備估價**：點一件裝備 → 依你填的顏色單價，算出製作 / 升級總花費；升級會**逐階列出**每一階的材料與小計。可依估價排序、依製作 / 升級篩選、依部位篩選。
- 上方可填「每種顏色材料單價」，會自動記住下次還在。顏色＝材料稀有度：
  - ⚪ 普通　🟢 進階　🔵 稀有　🟣 史詩
  - Zeny 一律以面額計算，不套顏色單價。
- 內容為**繁體中文**（資料以 `language=tw` 直接從官方取得）。
- 已包含：裝備（武器/副手/盔甲/披風/鞋子/飾品）+ **帽子**；已排除「神器」部位。

## 遊戲更新後，想重新抓最新資料

需要 Node.js（終端機輸入 `node -v` 有版本號即可）。在這個資料夾下：

```bash
node scrape.mjs       # 重新爬最新資料，存到 raw.json（可中斷續跑）
node build-html.mjs   # 由 raw.json 重新產生 index.html
```

- `scrape.mjs` 會打官方 API 抓「裝備清單 + 製作材料 + 升星材料」，有重試與限流，中途斷掉再跑一次會接續。
- 想強制全部重抓：先刪掉 `raw.json` 再跑 `node scrape.mjs`。

## 想調整內容（給會看程式的人）

打開 `build-html.mjs` 最上方幾個設定：

- `DEFAULT_PRICES`：四種顏色的預設單價。
- `EXCLUDE_POS`：要排除的部位（目前是 `14` 神器）。部位代號：1 武器、2 副手、3 盔甲、4 披風、5 鞋子、6 飾品、14 神器。

改完跑 `node build-html.mjs` 重新產生 HTML。

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `index.html` | 成品，直接打開用（也是對外網址首頁） |
| `scrape.mjs` | 爬蟲，產出 `raw.json` |
| `build-html.mjs` | 把 `raw.json` 轉成 `index.html` |
| `raw.json` | 爬下來的原始資料快取 |

## 資料來源備註

- 升級材料逐階呈現；估價的「升級總額」＝各階加總。
- 帽子只有製作材料，沒有升級。
- 來源 API 對少數裝備（4 件升級）回「資料不存在」，屬官方資料缺漏，已自動略過。
- 資料以繁中（`language=tw`）抓取；要簡中改 `scrape.mjs` 的 `LANG`。
